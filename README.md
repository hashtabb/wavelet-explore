# wavelet-explore
Image compression is a fundamental problem in computer science and mathematics. Many modern methods employ wavelet-like transforms (e.g. JPEG uses the famous Discrete Cosine Transform (DCT) ) in order to obtain lossy compressions which still maintain much of the visual integrity of the original image.

In the repo's Jupyter notebook, we walk through a brief introduction into image compression and how this problem can be tackled using Discrete Wavelet Transforms, using PyWavelet in Python. 

Also featured in the repo are a set of slides for a talk I gave at UPenn's applied math graduate student seminar explaining some background and more detail about the math that goes into the discrete wavelet transform.
